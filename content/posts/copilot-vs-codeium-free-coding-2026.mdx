Codeium, as a separate product, is hard to find now. As of 27 November 2026, codeium.com/pricing serves a page titled "Devin Plans and Pricing", and the plans on it are the same ones listed on windsurf.com/pricing: Free, Pro at $20 a month, Max at $200 and Teams at $80. So when people search "Copilot vs Codeium for free coding", the honest comparison is GitHub Copilot Free against the free plan of what Codeium became.

That is a better comparison than it sounds, because the two free tiers are built on opposite bets. Copilot Free limits completions and gives you agent access in a small allowance. Windsurf's free plan keeps completions unlimited and rations the agent. Which one you want depends on how you code.

## The verdict first

| Scenario | Winner | Why |
| --- | --- | --- |
| Autocomplete all day, free | Windsurf Free | Unlimited Tab completions and unlimited inline edits |
| Occasional completions plus chat | Copilot Free | 2,000 inline suggestions a month, with limited chat and agent usage |
| Cheapest paid upgrade | Copilot Pro | $10 a month with unlimited code completion and next edit suggestions |
| Paid plan with frontier models included | Windsurf Pro | $20 a month, with increased quotas for OpenAI, Claude and Gemini models |
| Code review and issue to pull request work | Copilot | Pro and above include pull request reviews and assigning work to Copilot |
| A plan that works inside JetBrains, Xcode and Eclipse | Copilot | Agent mode is listed for VS Code, Visual Studio, JetBrains, Eclipse and Xcode |

## What Copilot Free gives you

GitHub lists Free at $0 with no credit card, and says verified students get a separate Student plan. The comparison table is blunt about the limits. Inline suggestions are capped at 2,000 per month. Chat and agent usage are described only as limited. Pull request reviews, assigning work to Copilot and several other cloud features are not included on Free, though Free does include the CLI, agent mode in the major editors, MCP server support and custom instructions.

The cap is the part to plan around. At 2,000 suggestions a month, a developer who accepts completions all day can reach it within a couple of weeks. GitHub does not say what happens at the limit beyond the plan being limited, so check the behavior in your own editor before you rely on it.

## What the Codeium successor gives you

The Windsurf plan lists Free as a light quota to code with agents, limited model availability, unlimited inline edits and unlimited Tab completions. That is the reverse of Copilot's deal. You can complete code without counting, but agent runs are rationed and the model list is shorter.

The page does not publish the size of the agent quota, so there is no number to compare to Copilot's 2,000. If you mostly use autocomplete and occasional edits, the unlimited completions will feel better. If you want agents to do real work, you will hit the quota faster than you expect.

## The paid step up

Both products move to a paid plan at a small price, but the plans are shaped differently.

| Plan | Price | Notes |
| --- | --- | --- |
| Copilot Pro | $10 per user a month | Unlimited completion, model selection, cloud agent and code review, $15 monthly total credits |
| Copilot Pro+ | $39 per user a month | Premium models including Opus, 4x+ Pro usage, $70 monthly total credits |
| Copilot Max | $100 per user a month | High-volume agent work, $200 monthly total credits |
| Windsurf Pro | $20 a month | Frontier model quotas, free SWE-2, Devin Cloud agents, extra usage at API pricing |
| Windsurf Max | $200 a month | Significantly higher quotas, Devin Bots |

Copilot's credit system needs a closer look. GitHub splits its total credits into a base amount equal to the plan price and a flex allotment on top. Pro is $10 base plus $5 flex, Pro+ is $39 plus $31, and Max is $100 plus $100. The page says flex allotments may change over time, so do not treat the $15 figure as a promise. Agent mode, code review, the cloud agent and the CLI all draw from these credits, and you can buy more.

## Where each one fails

Copilot Free fails on the monthly cap. Once suggestions run out, the main thing you wanted from a free coding assistant is gone until the month resets. The paid Pro plan removes that cap for $10.

The Windsurf side fails on transparency, with quotas described but not quantified, and on identity. The brand on the pricing page is now Devin, and if you signed up to Codeium years ago, check what your account maps to before you assume anything about limits.

## Who should skip which

Skip Copilot Free if you write code all day and want completions you never count. Skip the Windsurf free plan if you need pull request review or a plan that sits inside your GitHub workflow. ## Which should you pick

If you want free autocomplete without a counter, install the Windsurf editor and use its free plan. If you live in GitHub, want reviews and issue to PR automation, and can live with a cap, start on Copilot Free and move to Pro at $10 when you hit 2,000 suggestions. Do not pay for either until one of those two limits actually annoys you.

## Frequently Asked Questions

### Is Codeium still a separate product?

Its pricing page at codeium.com/pricing now shows the same Devin and Windsurf plans as windsurf.com/pricing: Free, Pro at $20, Max at $200 and Teams at $80 a month.

### Is GitHub Copilot free?

Yes. Copilot Free costs $0 with no credit card, with 2,000 inline suggestions a month and limited chat and agent usage. Verified students can get a separate Student plan.

### Does Windsurf's free plan limit autocomplete?

No. Windsurf lists unlimited Tab completions and unlimited inline edits on Free, with a light quota for agents and limited model availability.

### How much does Copilot cost after the free plan?

Pro is $10 per user a month, Pro+ is $39 and Max is $100. Pro includes unlimited code completion, and each paid plan includes monthly AI credits for agent features.
