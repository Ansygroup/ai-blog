Yes. By uploading brand assets, Otter Palette extracts existing brand colors, then proposes new palettes that maintain contrast ratios required by WCAG 2.2 AA, ensuring both visual harmony and accessibility.

Enterprise customers receive a full RESTful API for Studio, Sketch, Palette, and Layout, allowing up to 10,000 requests per month at $0.02 per request. The API supports JSON payloads for prompt, asset, and layout specifications.
