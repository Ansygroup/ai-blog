Custom GPTs are going away. OpenAI's FAQ, updated 10 November 2026 and summarized by Blue Hat Web, sets a standard retirement date of 11 December 2026 for custom GPTs on every plan. That changes this comparison. Claude Projects and ChatGPT Projects are the lasting features, and custom GPTs are a migration problem. As of November 2026, here is how they differ. Last tested: 27 November 2026. Claude details are from Anthropic's help center. ChatGPT and retirement details come from [Blue Hat Web](https://www.bluehatweb.com/guides/ai-at-work/everyday-tasks/projects-and-custom-gpts/) (10 November 2026) and [Kipt](https://kipt.me/guides/chatgpt-projects-vs-claude-projects) (24 October 2026), since OpenAI's own project pages do not list limits.

## The verdict first

| Scenario | Winner | Why |
| --- | --- | --- |
| A reusable assistant you publish | Neither | Personal accounts can no longer create or publish GPTs |
| Large document sets in one workspace | Claude Projects | Paid plans switch to retrieval and expand capacity by up to 10x |
| Sharing with collaborators on any plan | ChatGPT Projects | Sharing works on every plan, up to 5 collaborators on Free |
| Project instructions applied to every chat | Claude Projects | Instructions apply to every chat in the project |
| Free plan | Tie | Free ChatGPT allows 5 files per project, free Claude allows up to 5 projects |
| Team sharing with view or edit rights | Claude Projects | Team and Enterprise get Can view and Can edit permissions |

## What happens to custom GPTs

The retirement rules from OpenAI's FAQ, as reported by Blue Hat Web:

| Date | What happens |
| --- | --- |
| 26 October 2026 | Enterprise workspaces stopped creating GPTs |
| Now | Free, Go, Plus and Pro accounts can no longer create or publish GPTs; existing ones can be used and edited |
| 11 December 2026 | Standard retirement date on every plan |
| 11 February 2027 | FedRAMP workspaces and approved exceptions |

After retirement GPTs and their pages cannot be opened, but your past conversations with them remain. A Migrate to plugin button in My GPTs turns instructions into a skill and knowledge files into reference files. It takes only the last published version, drops the chosen model and any custom actions, and makes the plugin private at first. The original GPT becomes read-only. OpenAI's pricing page still listed custom GPTs on Plus and Pro on 10 November, but the help center is more recent.

## Projects side by side

| | ChatGPT Projects | Claude Projects |
| --- | --- | --- |
| Free plan | Yes, 5 files per project | Yes, up to 5 projects |
| Files | 25 per project on Go and Plus, 40 on Pro, Business and Enterprise, 10 per upload | 30 MB per file, as many as fit in context, retrieval on paid plans |
| Instructions | Apply only in the project and override global custom instructions | Apply to every chat in the project |
| Sharing | Every plan, 5 collaborators on Free, 10 on Go and Plus, 100 on Pro | Team and Enterprise only |
| Memory | Default or project-only | Each project has its own memory |

Two details catch people out. In Claude, what you say in one chat of a project does not reach the others unless you add it to project knowledge. In ChatGPT, outside Enterprise and Edu, project chats can still draw on conversations outside the project unless it uses project-only memory.

Claude also has a new project version in beta, rolling out in stages starting with Claude Code to select Pro, Max and Ultra users. In it a project is one conversation that Claude splits into parallel threads in the cloud. Anthropic says nothing is lost when existing projects move, and that running several threads uses your plan usage faster.

## Where each one fails

Claude Projects fail for solo sharing, since sharing is limited to Team and Enterprise. Cross-chat memory inside a project is not automatic. ChatGPT Projects fail on file counts, since 25 files on Plus is small next to Claude's context based limit, and the custom GPT path is closing.

## Who should skip which

Skip ChatGPT custom GPTs entirely if you are starting now, and migrate any you rely on before 11 December. Skip Claude Projects if you need to share a workspace with outside collaborators on a personal plan. ## Test it yourself

1. Pick a document set of about 20 files you actually use.
2. Upload it to a Claude project and a ChatGPT project and ask five questions with known answers.
3. Note which tool needs fewer reminders about your instructions.
4. Open a second chat in each project and ask something from the first chat to test memory.
5. If you have a custom GPT, try Migrate to plugin on a copy of the instructions, and check what it dropped.

## Which should you pick

Pick Claude Projects for big, stable document sets and consistent instructions. Pick ChatGPT Projects if you need cheap sharing with several collaborators. If you rely on custom GPTs, start migrating now, since the retirement date is 11 December 2026.

## Frequently Asked Questions

### Are custom GPTs being retired?

Yes. OpenAI's FAQ updated 10 November 2026 sets a standard retirement date of 11 December 2026, with 11 February 2027 for FedRAMP workspaces and approved exceptions.

### Can I still create a custom GPT?

Not on personal accounts. Free, Go, Plus and Pro accounts can no longer create or publish GPTs, though existing ones can be used and edited until retirement.
