## FAQ

### How does Otter.ai DevSpeak handle code in multiple languages within the same project?

Otter.ai’s DevSpeak uses a language‑agnostic transformer that automatically detects the current file’s language and offers context‑aware completions. Switching between JavaScript, Python, and Go within a single session incurs no additional latency.

### Can I integrate GitHub Copilot with Visual Studio 2026?

Yes. Visual Studio 2026 includes a native Copilot extension that supports both inline suggestions and code generation via the “Copilot Chat” panel. It also integrates with GitHub Actions for automated review prompts.

### Does Tabnine Pro support on‑prem deployment for GDPR compliance?

Absolutely. Tabnine Pro offers a Docker‑based on‑prem deployment that stores all model inference locally, ensuring no data leaves your data center.

### Is Amazon CodeWhisperer free for all AWS users?

Amazon CodeWhisperer is free for all AWS customers under the standard tier. However, enterprise features—such as enhanced security analysis and dedicated support—require a paid subscription.

### What is the difference between Otter.ai’s free and premium plans?

The free plan allows 600 minutes of transcription per month, sufficient for a 20‑hour sprint. The premium plan removes limits, adds advanced analytics, and unlocks the DevSpeak module’s full feature set.
