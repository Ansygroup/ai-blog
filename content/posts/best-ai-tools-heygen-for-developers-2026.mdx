```json

```

The Free tier grants **30 minutes of video rendering per month**, which is enough for prototyping up to 5 [short](/posts/how-to-use-ai-for-instagram-reels-2026) (≈6 minute) clips.

### Does HeyGen support custom voice [cloning](/posts/best-ai-tools-suno-for-translators-2026)?

Yes. HeyGen offers a **Voice Cloning** add‑on ($199/mo) that lets you upload up to 30 seconds of reference [audio](/posts/ai-generated-podcast-intro-outro-music-tutorial-2026) and generate a synthetic voice that matches your brand’s tone.

### Can I host the rendered videos on my own CDN?

Absolutely. HeyGen returns a signed URL that you can download and re‑host on any CDN (e.g., CloudFront, Akamai). The API also supports **direct [streaming](/posts/bahrain-grand-prix-in-malaysia-f1-free-2026-guide)** via HLS if you enable the “stream” flag in the request payload.

### Is there a limit on avatar selections per project?

The avatar library is unlimited for [paid](/posts/copy-ai-vs-free-version) plans. Free users can access **500** of the most popular avatars; the rest are gated behind the Starter tier.

### How does HeyGen handle data privacy for uploaded [scripts](/posts/ai-tutorial-youtube-shorts-scripts-thumbnails-2026)?

All script data is encrypted at rest using AES‑256 and transmitted over TLS 1.3. HeyGen does not retain scripts longer than **30 days** unless you enable “persistent storage” in the dashboard.

### What languages are available for HeyGen’s text‑to‑[speech](/posts/best-ai-tools-elevenlabs-for-translators-2026)?

HeyGen currently supports **15 languages** (including English, Spanish, Mandarin, German, French, Japanese, Korean, Portuguese, Italian, Dutch, Russian, Arabic, Hindi, Turkish, and Swedish) with **30+ voice styles**.
