## What Is ElevenLabs API?

ElevenLabs provides a cloud‑based TTS API that converts raw text into lifelike speech using deep‑learning voice models. The service offers three main voice families:

1. **Standard Voices** – 30+ generic voices suitable for announcements and IVR.
2. **Premium Voices** – 12 hyper‑realistic voices trained on extensive speech corpora, ideal for podcasts, audiobooks, and video narration.
3. **Custom Voices** – Users can upload up to 30 minutes of their own audio to create a brand‑specific voice.

The API returns audio in MP3 or WAV formats, supports SSML tags for pauses and emphasis, and integrates with popular platforms via RESTful endpoints. In 2026 the platform added **real‑time streaming** (latency < 150 ms) and **batch processing** for bulk generation, which directly impacts cost calculations.

## FAQ

### How does ElevenLabs charge for custom voice creation?
ElevenLabs bills custom voice fine‑tuning at **$0.10 per minute of uploaded audio**. A typical 10‑minute brand voice costs $1.00, plus the standard per‑character rate for generated speech.

### Is there a discount for high‑volume usage?
Yes. Enterprise customers negotiating > 5 M characters per month can receive **up to 45 % off** the listed rates, with custom SLAs and dedicated support.

### What formats does the ElevenLabs API return?
The API supports **MP3 (128 kbps), MP3 (320 kbps), WAV (16‑bit, 44.1 kHz)**, and **OGG**. You can specify the format via the `output_format` parameter in the request body.

### Does ElevenLabs offer a free trial?
The Free tier provides **5 000 characters each month** with access to both Standard and Premium voices, allowing developers to test quality and latency without a credit card.

### How does latency compare with Google Cloud TTS?
ElevenLabs’ real‑time streaming endpoint averages **120 ms latency**, slightly faster than Google Cloud’s 150 ms average, making it better suited for live‑chat or interactive voice applications.

### Are there any hidden fees I should watch for?
Beyond per‑character rates, keep an eye on **storage fees ($0.005 / GB)** and **fine‑tuning costs** if you create custom voices. There are no per‑API‑call fees, but exceeding the free tier will trigger the per‑character charge immediately.
