Shopify’s Conversational Designer includes built‑in **WCAG 2.2 checks**. When you ask for a button, the AI adds `aria-label` and ensures sufficient color contrast (minimum 4.5:1). For example, a prompt like “Create a dark‑mode toggle” results in a button that meets contrast guidelines and includes keyboard focus styles.

However, the tool is not a substitute for a professional accessibility audit. In one case, the AI suggested a carousel that auto‑rotated every 2 seconds—something we manually disabled to avoid WCAG violations. Overall, the AI provides a solid baseline, but merchants should still run a final accessibility review.

## FAQ

### How does the Conversational Designer differ from Shopify’s Theme Editor?

The Conversational Designer uses natural language to generate entire sections, while the Theme Editor is a visual drag‑and‑drop tool that requires manual placement of pre‑built blocks. The AI also adds SEO, accessibility, and app integration code automatically.

### Can I export the AI‑generated sections to another Shopify store?

Yes. Each generated section is saved as a **Liquid snippet** that you can download from the theme files and import into any other Online Store 2.0 theme.

### Does the AI store any of my prompts or store data?

Shopify stores prompts **temporarily** for session continuity and deletes them after 30 days, complying with GDPR and CCPA. No personally identifiable information is retained beyond what’s needed for model improvement.

### What happens if the AI makes a mistake in the code?

All generated code passes Shopify’s theme‑lint validator, but edge cases can occur. The version control feature lets you revert to a previous draft instantly, and the built‑in **code inspector** highlights any syntax errors for quick manual fixes.

### Is there a limit to the number of languages the AI can handle?

The Pro plan supports **up to 12 languages** per store, leveraging Shopify Translate & Adapt. Adding more languages requires an Enterprise agreement.
