## Integration & API Support

Writesonic’s API is designed for **plug‑and‑play**. Here’s a quick example of invoking the code generation endpoint from a Node script:

```js
const fetch = require('node-fetch');

async function generateCode(prompt) {
  const response = await fetch('https://api.writesonic.com/v1/code', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${process.env.WRITESONIC_API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({ prompt, language: 'python', max_tokens: 800 })
  });
  const { code } = await response.json();
  return code;
}

generateCode('Create a Flask endpoint that returns JSON of the current server time')
  .then(console.log)
  .catch(console.error);
```

The API supports **streaming responses**, **batch generation**, and **webhook callbacks** for asynchronous pipelines. Integration with CI tools like GitHub Actions is straightforward:

```yaml
name: AI‑Generated Tests
on: push]
jobs:
  generate-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Call Writesonic
        env:
          WRITESONIC_API_KEY: ${{ secrets.WRITESONIC_API_KEY }}
        run: |
          curl -X POST https://api.writesonic.com/v1/code \
            -H "Authorization: Bearer $WRITESONIC_API_KEY" \
            -H "Content-Type: application/json" \
            -d '{"prompt":"Write Jest tests for src/utils.js","language":"javascript"}' \
            > generated-tests.js
      - name: Run Tests
        run: npm test
```

These snippets illustrate why **DevOps teams** can embed Writesonic directly into their pipelines without extra middleware.
