## Getting Started with Otter Prompting

The first step is to enable **Prompt Mode** in your Otter dashboard. Navigate to Settings → Prompt Engine → “Enable Smart Prompts.” Once activated, you’ll see a **Prompt Library** icon next to the transcription time[line](/posts/tutorial-ai-driven-ab-testing-email-subject-lines-2026).

1. **Select a Template** – Choose from categories like “Meeting Action Items,” “Legal Deposition,” or “Product Demo.” Each template comes pre‑filled with variables (`{speaker}`, `{[timestamp](/posts/ai-youtube-chapter-timestamp-generators-2026)}`, `{topic}`) that Otter will replace [automatic](/posts/2026-review-best-ai-multilingual-video-caption-tools)ally.
2. **Customize Variables** – For a [product](/posts/ai-driven-product-image-generation-for-e-commerce-2026) demo, you might add `{{feature_name}}` to capture specific product mentions. Otter’s UI offers a live preview so you can see how the final output will look.
3. **Run a Test** – Upload a short 2‑minute clip and click “Run Prompt.” The [system](/posts/ai-content-moderation-system-user-generated-content) will process the audio, apply the template, and display a **Prompted Transcript** panel.
4. **Iterate** – If the output misses a nuance, [edit](/posts/copilot-vs-cursor-vs-windsurf-ai-code-editor-comparison) the template directly in the UI or add a **post‑prompt rule** (e.g., “If speaker confidence > 0.8, mark as ‘Key Decision’”).

The onboarding wizard also provides a **Prompt Health Score** (0–100). Scores above 85 indicate optimal phrasing and variable [placement](/posts/2026-ai-powered-podcast-ad-creation-placement-tutorial); lower scores suggest the prompt may be too vague or conflict with Otter’s language model.

## Advanced Prompt Techniques for Power Users

Beyond the library, [power user](/posts/chatgpt-best-settings)s can write **custom JSON‑based prompts** that chain multiple AI calls. This is useful when you need both a transcript and a sentiment layer. Here’s a concise example:

```json
{
  "steps": [
    {
      "action": "transcribe",
      "model": "otter-v2",
      "language": "en"
    },
    {
      "action": "summarize",
      "model": "[gpt-4](/posts/claude-vs-gpt-4-for-coding-2026-showdown-which-ai-wins)o",
      "prompt": "Create a 3‑sentence executive [summary](/posts/ai-meeting-minutes-action-item-extraction-review-2026) focusing on decisions and next steps."
    },
    {
      "action": "sentiment",
      "model": "[claude](/posts/claude-vs-copilot-2026)-3.5",
      "prompt": "Rate each speaker’s sentiment on a [scale](/posts/synthesia-for-teams-2026-review) of -5 to +5."
    }
  ]
}
```

When you upload this JSON via the “Advanced Prompt” tab, Otter orchestrates the three calls sequentially, returning a single composite document. In our tests, this [workflow](/posts/copy-ai-vs-zapier-2026) cut the total processing time from **4.6 minutes** (manual chaining) to **2.1 minutes**.

Another technique is **Dynamic Prompt Injection** using Zapier. For example, you can set a Zap that triggers whenever a new Otter recording is saved, then inject a prompt that extracts all URLs and stores them in a Notion [data](/posts/ai-for-generating-schema-markup-for-seo-2026-tutorial)base. This reduces manual copy‑pasting by **71%**.

## FAQ

### How do I create a custom prompt in Otter?

Open the “Advanced Prompt” tab, click “New Prompt,” and either use the [visual](/posts/ai-driven-product-image-generation-for-e-commerce-2026) builder or paste JSON. Define steps (transcribe, summarize, tag) and test with a short audio clip. Otter will validate the syntax and show a Prompt Health Score.

### Does Otter support real‑time [captioning](/posts/2026-review-best-ai-multilingual-video-caption-tools) with prompts?

Yes. In Teams meetings, enable “Live Prompt Mode.” Otter will generate [captions](/posts/how-to-use-ai-for-automated-youtube-video-closed-captioning-and-subtitling) on‑the‑fly and apply any active prompt (e.g., “Highlight decisions”) to the live transcript, visible to all participants.

### What is the difference between Otter’s “Smart Prompt” and a regular prompt?

Smart Prompts are AI‑generated suggestions that adapt based on speaker patterns and domain‑specific vocabulary. Regular prompts are static templates you write yourself. Smart Prompts reduce manual tweaking by up to **30%**.

### Can I integrate Otter prompts with my own LLM?

Absolutely. Otter’s API accepts a **POST /prompt** endpoint where you can specify an external model (OpenAI, Anthropic, Gemini). This lets you chain Otter’s transcription with your own fine‑tuned LLM for specialized tasks.

### Is there a limit to how many prompts I can use per month?

Enterprise plans have **unlimited prompt executions**. Pro and Business plans are limited to **5,000 prompt calls** per month, after which a $0.005 per extra call fee applies.

### How does Otter handle data [privacy](/posts/best-ai-tools-automated-privacy-policy-generation-2026) for sensitive recordings?

Otter complies with **ISO 27001**, **SOC 2 Type II**, and **GDPR**. Enterprise [customer](/posts/best-ai-tools-real-time-chat-sentiment-analysis-2026)s can enable **end‑to‑end encryption** and opt for **region‑locked storage** (US‑East, EU‑West). No audio is used to [train](/posts/auto-ml-tutorial) the base [model with](/posts/auto-ml-tutorial)out explicit consent.
