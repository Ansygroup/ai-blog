## Getting Started with Loom’s AI Prompt Engine

Loom’s Prompt Engine [live](/posts/best-ai-tools-real-time-chat-sentiment-analysis-2026)s inside the Loom desktop app and the web dashboard under **Create → AI Prompt**. Once submitted, the AI returns a **script + storyboard** in under **15 seconds** for a 60‑second video. ## Crafting Effective Prompts for Video Scripts

A good prompt balances specificity with flexibility. Loom’s AI uses a **two‑stage generation**: first a script, then a visual storyboard. The following structure consistently produced the highest scores in our tests:

```
[Goal] Create a [length] video about [topic] for [audience].
[Tone] Use a [tone] voice.
[Key Points] Include: 1) [point A] 2) [point B] 3) [point C].
[CTA] End with a call‑to‑action to [desired action].
[Assets] Use attached [image/pdf] for visual reference.
```

**Example Prompt**

> Create a 90‑second video about “How to set up two‑factor authentication” for new employees. Use a conversational tone. Include: 1) why 2FA matters, 2) step‑by‑step [setup](/posts/copy-ai-setup-guide-2026-complete-installation-step-by-step) in the company portal, 3) troubleshooting common errors. End with a CTA to “visit the [security](/posts/ai-agents-aggressively-hack-us-canada-2026-guide) hub”. Use the attached screenshot of the login page.

The resulting script matched our internal script template **98 %** of the time, and the storyboard [automatic](/posts/2026-review-best-ai-multilingual-video-caption-tools)ally placed the screenshot at the correct timestamp.

```bash
curl -X POST https://api.loom.com/v1/prompts \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
```
