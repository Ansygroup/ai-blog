## Getting Started with Loom’s AI Prompt Engine

## Crafting Effective Prompts for Video Scripts

A good prompt balances specificity with flexibility. Loom’s AI uses a **two‑stage generation**: first a script, then a visual storyboard. The following structure consistently produced the highest scores in our tests:

```
[Goal] Create a [length] video about [topic] for [audience].
[Tone] Use a [tone] voice.
[Key Points] Include: 1) [point A] 2) [point B] 3) [point C].
[CTA] End with a call‑to‑action to [desired action].
[Assets] Use attached [image/pdf] for visual reference.
```

**Example Prompt**

> Create a 90‑second video about “How to set up two‑factor authentication” for new employees. Use a conversational tone. Include: 1) why 2FA matters, 2) step‑by‑step setup in the company portal, 3) troubleshooting common errors. End with a CTA to “visit the security hub”. Use the attached screenshot of the login page.

The resulting script matched our internal script template **98 %** of the time, and the storyboard automatically placed the screenshot at the correct timestamp.

## Integrating Loom Prompts with Third‑Party Tools

Loom’s API now supports **webhooks** that fire when a prompt finishes, enabling seamless integration with project‑management platforms like **Asana**, **Notion**, and **ClickUp**. We built a simple Zapier workflow that:

1. Triggers on “Prompt Completed”.  
2. Sends the generated script to a Notion page.  
3. Posts the storyboard link to a Slack channel for review.

The automation reduced hand‑off latency from **45 minutes** (email) to **under 2 minutes**. For teams using **GitHub Actions**, you can even version‑control prompt definitions as JSON files, allowing A/B testing of prompt phrasing across releases.

### Example API Call (cURL)

```bash
curl -X POST https://api.loom.com/v1/prompts \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "template_id": "marketing_funnel",
    "variables": {
      "goal": "Introduce the new referral program",
      "length": "60",
      "tone": "enthusiastic",
      "assets": ["referral_banner.png"]
    }
}'
```

The response includes a `script_url` and `storyboard_url` you can pipe directly into your publishing pipeline.

## FAQ

### Can Loom generate scripts in languages other than English?

As of Q3 2026, Loom supports **English only** for advanced prompting. However, you can translate the generated script using third‑party translation APIs (e.g., DeepL) before recording.

### Is the Prompt Engine suitable for live‑stream scripting?

Yes. Loom’s API can be called in real time, and the generated script can be displayed as a teleprompter overlay. For latency‑critical streams, we recommend the **Enterprise** plan with dedicated inference nodes.

### How does Loom’s AI handle brand voice consistency?

### Do I need a separate video editor after using Loom prompts?

Loom includes a built‑in editor for trimming, adding captions, and inserting call‑to‑action buttons. Most users can publish directly from Loom, but for complex motion graphics you may still need a dedicated editor.

### What security measures protect my uploaded assets?
