## MidJourney Prompt Builder – Streamlining Lesson Visuals

**MidJourney Prompt Builder** (MPB) is a browser extension and standalone web app that offers a curated library of over **1,200** education‑focused prompts. Teachers can filter by subject, grade level, and visual style (e.g., watercolor, isometric). MPB syncs with a MidJourney account via OAuth, automatically appending the correct “–v 5.2” version flag.

- **Pricing:** Free tier (10 prompts/month), Pro tier $19/mo (unlimited prompts, bulk export CSV).
- **Key Feature:** “Smart Prompt Refine” uses a lightweight LLM to suggest synonyms that improve image fidelity, cutting average render time from 45 seconds to 28 seconds.
- **Real‑World Example:** A 7th‑grade science teacher used MPB to generate 30 distinct cell‑structure diagrams in a single class period, saving roughly **2 hours** of manual searching.

MPB’s simplicity makes it ideal for teachers who already have a MidJourney subscription and want a plug‑and‑play prompt manager without additional licensing overhead.
