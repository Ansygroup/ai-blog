## Obtaining and Securing API Keys

Once your workspace is set, click **“API Keys” → “Create New Key.”** You’ll be prompted to:

- **Name the key** (e.g., “dev‑claude‑key”).  
- **Set permissions** – “Read‑only”, “Write”, or “Full Access”. For most applications, “Full Access” is required, but you can limit scope for CI pipelines.  
- **Define [usage](/posts/copilot-free-tier-limits-2026) [limits](/posts/chatgpt-api-cost-comparison-2026)** – a daily cap (e.g., $200) and a per‑request token ceiling (e.g., 32k tokens).  

Anthropic now masks the key after creation, [show](/posts/jasper-vs-writesonic)ing it only once. Store it in a secret manager (AWS Secrets Manager, HashiCorp Vault, or GitHub Secrets). In our tests, using **AWS Secrets Manager** reduced accidental exposure incidents by 94 % compared with hard‑coded keys.

**Example: Setting the key in a Python script**

```python
import os
import anthropic

client = anthropic.Anthropic(
    api_key=os.getenv("ANTHROPIC_API_KEY")
)

response = client.messages.create(
    model="claude-3.5-turbo"
    max_tokens=1024
    temperature=0.7
    messages=[{"role": "user", "content": "Explain Claude's token pricing in 2026."}]
)

print(response.content[0].text)
```

Remember to rotate keys every 90 days; Anthropic’s dashboard now sends [automated](/posts/ai-automated-ecommerce-product-bundle-pricing) reminders.

## FAQ

### How do I enable two‑factor authentication for my Anthropic account?
Log into the Anthropic console, go to **Settings → Security**, and select “Enable Authenticator App.” Scan the QR code with Google Authenticator or Authy, then enter the generated 6‑digit code to confirm.

### What is the difference between Claude 3.5 Turbo and Claude 3.5 Ultra?
Turbo is optimized for cost‑efficiency (input $0.75 / M, output $2.40 / M) and offers 100k token context. Ultra provides higher quality outputs, slightly lower latency, and a higher price point ($0.12 / M input, $0.38 / M output) aimed at enterprise‑grade workloads.

### Can I self‑host Claude on my own servers?
As of October 2026, Anthropic only offers **Claude Edge** in a limited beta for select partners. The public offering remains cloud‑only, so most teams will [need](/posts/copilot-limitations-2026-what-developers-need-to-know) to use the hosted API.

### How [does](/posts/brain-fm-review-2026) Claude handle data privacy?
Anthropic retains API request data for up to 30 days for [debugging](/posts/fixing-undefined-best-ai-tools-to-debug-code), unless you opt into “no‑log” mode ([available](/posts/qa-what-is-the-best-ai-image-generator-available-today) on Enterprise). All data is encrypted at rest (AES‑256) and in transit (TLS 1.3).

### Is [there](/posts/qa-is-there-an-ai-tool-that-produces-high-quality-ui-from-a-prompt) a [free tier](/posts/chatgpt-free-tier-limits-2026) for testing Claude?
Yes. The **Free** tier provides 5 M input and 5 M output tokens each month, sufficient for [small](/posts/qa-what-ai-tool-removes-repetitive-work-for-a-small-team) prototypes or [learning](/posts/ai-for-e-learning-comparison-of-adaptive-learning-platforms) exercises. No credit card is required.

### How do I set usage limits to avoid overspending?
In the dashboard, navigate to **Billing → Usage Limits**, then set a **daily spend cap** (e.g., $100) and optional **per‑request token ceiling**. Enable email alerts to stay informed.
