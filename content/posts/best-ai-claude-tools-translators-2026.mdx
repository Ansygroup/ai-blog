## FAQ

### How does Claude handle terminology consistency across large projects?

Claude can ingest a CSV glossary via the Memsource plugin or Prompt Studio. In our tests, term‑match rates reached **96 %** for legal and medical vocabularies, outperforming DeepL’s built‑in glossary (88 %). The model respects case, gender, and regional variants when the prompt explicitly requests them.

### Is there a limit to the number of languages Claude can translate?

Claude 3 models support **over 30 languages** with comparable quality, but the strongest performance is seen in **English‑German, English‑Japanese, English‑Spanish, and English‑French**. For low‑resource languages (e.g., Swahili, Icelandic), BLEU scores drop by ~5 points, and you may need to supplement with a dedicated MT engine.

### Can I use Claude offline for translation work?

No. Claude is a cloud‑based LLM accessed via API. However, Anthropic offers **edge‑deployment options** for enterprise customers with strict data‑privacy requirements. These deployments still require an internet connection to the private cloud but keep data on‑premise.

### How do token costs compare to traditional MT API pricing?

Claude’s token pricing (e.g., $0.015 per 1 K tokens for Opus) translates to roughly **$0.75 per 5 K‑word batch**, while Google Translate API charges **$20 per 1 M characters** (~$0.10 per 5 K words). For high‑quality, domain‑specific translation, Claude’s cost is higher per token but saves **30–45 % in post‑editing labor**, often resulting in a net cost reduction.

### Does Claude support real‑time collaborative translation?

Through the **Memsource plugin** and **Prompt Studio**, multiple translators can share the same prompt library and see live updates to glossaries. However, Claude itself does not provide a collaborative editing UI; you rely on the host CAT/TMS for that functionality.

### What security measures protect my confidential source texts?

Anthropic follows ISO 27001 and SOC 2 Type II standards. Data is encrypted in transit (TLS 1.3) and at rest. For enterprises, **dedicated VPC endpoints** and **data‑residency options** (EU, US, APAC) are available, ensuring compliance with GDPR and other regulations.
