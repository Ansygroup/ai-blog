## FAQ

### How does Jasper’s Design Prompt differ from regular Jasper copy generation?
Design Prompt adds a visual‑ideation layer. While standard Jasper produces only text, Design Prompt returns layout suggestions, SVG mockups, and image‑generation prompts tailored for Midjourney or Firefly, all within the same query.

### Can Jasper generate vector graphics directly?
No. Jasper creates **SVG placeholders** and image prompts. For true vector output, you must send the prompts to a tool like Midjourney V6 (raster) or Adobe Firefly (vector‑aware). Jasper’s strength lies in coupling copy with visual direction.

### Is Jasper’s API compatible with Figma plugins?
Yes. Jasper offers a RESTful API and a dedicated Figma plugin (released Q2 2026). The plugin lets you select a frame, type a brief, and receive copy and image suggestions that populate directly into the selected layer.

### How many image credits does the Creative Plan actually provide?
The Creative Plan includes **15 k credits**, which translates to roughly **300 high‑resolution (4 K) images** using Midjourney’s average 50‑credit cost per render. You can also allocate credits to DALL·E 3 or Adobe Firefly if preferred.

### Does Jasper support team collaboration?
Absolutely. Jasper Studio is a shared workspace where team members can comment, approve, or reject AI‑generated assets. Activity logs and version history are built‑in, making it easy for managers to track AI contribution to projects.

### What are the privacy implications of feeding client briefs into Jasper?
Jasper follows GDPR‑compliant data handling. All prompts are encrypted at rest, and you can enable “Enterprise Data Isolation” (available on Business plans) to ensure client information never leaves your organization’s private cloud.
