## Integrating AI with Instagram Reels Analytics

Understanding post‑performance is essential for scaling. AI‑driven analytics go beyond basic metrics by offering predictive insights.

- **Meta’s Reels Insights API** now supports “AI‑augmented sentiment analysis,” which classifies comments as positive, neutral, or negative with 92% accuracy.  
- **Socialbakers AI** aggregates these sentiment scores across multiple posts to suggest content pivots (e.g., “increase product‑demo clips” if sentiment drops).  

By exporting the data into a simple Google Sheet and using OpenAI’s **function calling** feature, you can generate a weekly performance summary automatically. The script looks like:

```python
import openai, pandas as pd

df = pd.read_csv('reels_metrics.csv')
summary = openai.ChatCompletion.create(
    model="gpt-4o-mini",
    messages=[
        {"role":"system","content":"Summarize Instagram Reels performance for the week."},
        {"role":"user","content":df.to_json()}
    ]
)
print(summary.choices[0].message.content)
```

The resulting narrative highlights top‑performing Reels, suggests new topics, and even predicts the next week’s optimal posting window.
