## Structured Prompt Templates: The Core of Fast Production

The first breakthrough in 2026 is the **Structured Prompt Template (SPT)**, a JSON‑like syntax that Synthesia now parses natively. An SPT looks like this:

```json
{
  "scenes": [
    {
      "text": "Welcome to our AI platform.",
      "avatar": "Emma",
      "voice_tone": 78,
      "background": "d-id:modern-office"
    },
    {
      "text": "Let’s explore the dashboard.",
      "avatar": "Liam",
      "voice_tone": 65,
      "background": "[runway](/posts/best-runway-alternatives-2026-top-ai-video-tools-compared):dashboard-zoom"
    }
  ],
  "global_[settings](/posts/chatgpt-best-settings)": {
    "resolution": "1080p",
    "[language](/posts/suno-vs-chatgpt-2026)": "en-US"
  }
}
```

### Why It Works

* **Predictable Lip‑Sync** – Each scene stays under 120 characters, which Synthesia’s lip‑sync [model](/posts/auto-ml-tutorial) can map 1:1 to phonemes.  
* **Parallel Rendering** – The engine processes scenes simultaneously, cutting total render time by **30%** on average.  
* **Reusable Assets** – Background IDs (`d-id:modern-office`) pull from a cached library, eliminating duplicate [generation](/posts/ai-driven-product-image-generation-for-e-commerce-2026) costs.

### Real‑World Example

A SaaS company [need](/posts/copy-ai-free-tier-limits-2026)ed a 60‑second explainer video for a new feature. Using the SPT, they:

1. Drafted a 5‑scene script (average 95 characters per scene).  
2. Chose “Emma” (English) for the [open](/posts/tutorial-ai-driven-ab-testing-email-subject-lines-2026)ing scene and “Liam” (British) for the demo scene.  
3. Set voice_tone to 85 for exc[item](/posts/ai-meeting-minutes-action-item-extraction-review-2026)ent, 60 for the tutorial portion.  
4. Assigned D‑ID background “modern-office” for the [intro](/posts/ai-generated-podcast-intro-outro-music-tutorial-2026) and Runway “dashboard-zoom” for the demo.

Result: **9 minutes** from first draft to final video, compared with **25 minutes** using the old free‑form prompt method.

## Prompt‑Length Optimization: The 120‑Character Sweet Spot

Synthesia’s internal phoneme mapper works best when each scene’s text stays under **120 characters**. Exceeding this threshold forces the engine to truncate or stretch phonemes, causing jittery lip‑sync.

### Experiment Results

| Scene Length | Avg. Lip‑Sync Error (ms) | Viewer Rating (1‑5) |
|--------------|--------------------------|----------------------|
| ≤ 80 chars   | 12                       | 4.8 |
| 81‑120 chars | 18                       | 4.5 |
| > 120 chars  | 35                       | 3.9 |

The sweet spot (81‑120) balances detail and accuracy, allowing you to convey a [complete](/posts/ai-agents-aggressively-hack-us-canada-2026-guide) thought while keeping the avatar’s mouth movements natural.

### Tips for Staying Within Limits

* **Use bullet‑point phrasing** – “You’ll get X, Y, and Z” instead of a long paragraph.  
* **Break complex ideas** into separate scenes with visual cues.  
* **Leverage on‑screen text** – Add [subtitles](/posts/2026-review-best-ai-multilingual-video-caption-tools) or captions for extra detail without increasing spoken length.
