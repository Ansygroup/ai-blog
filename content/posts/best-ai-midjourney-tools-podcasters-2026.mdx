## FAQ

### How does MidJourney’s licensing work for podcasters?

MidJourney Pro grants an **exclusive commercial license** on each generated image, meaning you can use the cover art on all platforms, merch, and advertising without attribution. The license is non‑transferable but remains valid as long as you maintain an active subscription.

### Can I automate prompt generation for each episode?

Yes. PromptHero’s API allows you to feed episode titles, guest names, and keywords to generate a custom prompt automatically. We built a Zapier workflow that creates a new MidJourney job within 5 seconds of publishing the episode on Anchor.

### Is the AI‑generated cover art SEO‑friendly?

Google’s image SEO guidelines focus on file size, alt text, and relevance. MidJourney images can be exported as **WebP** (≤150 KB) and paired with descriptive alt tags generated by tools like **ChatGPT SEO**. In our tests, episodes with AI‑optimized alt text saw a **5 %** boost in organic discoverability.

### Do I need a powerful GPU to use MidJourney?

No. MidJourney runs on its own cloud infrastructure, so a standard laptop or desktop with an internet connection is sufficient. However, upscaling tools like Topaz Gigapixel benefit from a local GPU (RTX 3080 or better) for faster processing.

### How does Headliner.ai compare to free audiogram generators?

Free tools (e.g., **Wavve**) often limit export resolution and lack AI‑driven waveform synchronization. Headliner.ai’s **Auto‑Audiogram** reduces manual key‑framing by 90 % and supports 1080 p output, which translates to higher engagement on mobile platforms.

### What alternatives exist to ClipDrop for upscaling?

Topaz Gigapixel AI offers higher maximum upscales (6×) and slightly better SSIM scores, but at a one‑time cost of $99. For podcasters on a tight budget, ClipDrop’s subscription model ($12/mo) provides ample quality for most use cases.
